# Changelog

本插件遵循 [Semantic Versioning](https://semver.org/)。

## [Unreleased]

**图文混排重做**：图片不再作为独立类型单独存放 + 附一条备注，而是直接嵌进正文与文字混合排版；另含上一轮「列表图片展示」的体验与性能重构。

### 变更（破坏性）

- **数据模型**：memo 新增 `images[]`（每张图的槽 ID / MIME / 指纹 / 尺寸 / OCR 文本），正文以 `{img:<槽ID>}` 标记在任意位置引用图片（同一图可多处引用）；v1 单图字段（mime/imageHash/imageWidth/imageHeight/imageBytes）读取时自动升级为 `images[0]`，宿主路径在启动时把旧附件从 memo 文档物理搬迁到独立桩文档 `sm/att/<槽ID>`（幂等，读取始终兼容旧位置）
- **kind 语义收窄**：`image` 仅指「纯图条目」（正文除图片标记外无文字）；带文字的图文条目为 `text`。**回车行为**：纯图条目粘贴图片本体（与旧版一致）；图文混排条目粘贴文字（图片标记剥离），列表/预览中点击行内图片即复制该图
- 旧版「图片 + 备注」条目升级后变为混排条目（图片在前、备注在后），Enter 从贴图改为贴文字
- 预览面板行内编辑不再支持含图条目（避免文本域暴露图片标记），完整编辑走「编辑备忘」

### 新增

- **混排编辑器**：正文从 textarea 换成 contenteditable 自研编辑器——图片以行内缩略图嵌在正文里原地排版，Ctrl/⌘+V 粘贴图片或**拖入图片文件**即在光标处插入，退格整图删除；文本粘贴强制纯文本（不带富文本样式）；Enter/Tab 沿用原 textarea 语义（换行/两空格缩进）；IME 组合期间不打断
- **行内图片渲染**：列表摘要中的图片渲染为小徽标（点击复制该图）；展开区/预览面板渲染为限高缩略图（点击复制、双击全屏）；混排条目元信息显示图片张数
- **多图支持**：单条备忘最多 32 张图（每张 ≤8MB）；创建副本时图片槽整体换新 ID 并改写正文标记（与原图独立）；全屏查看 `←/→` 在当前列表**全部图片**（跨条目、含混排行内图）间翻页
- **OCR 逐图识别**：含图条目保存后自动识别（只识别还没有文字的图，不重复计费）；结果按图存 `images[].ocrText` 并合并为检索视图；部分失败给出张数提示
- **导入导出**：JSON 按「槽 ID → 像素」携带图片，新增条目重分配 memoId 时槽 ID 一并重分配并改写正文标记（旧版导出按 memoId 键值天然兼容）；Markdown/CSV 导出把图片标记替换/剥离为 `[图片]` 占位；「图片」筛选与计数改为「含图条目」

### 内部

- 缩略图管线、全尺寸展示缓存（上限 24→64）、dataURL 缓存全部改按图片槽 ID 寻址（不再假设一条备忘只有一张图）；`contentKey` 判重按图片指纹集合；检索内容把图片标记等长掩码（高亮下标与原文对齐）

### 列表图片体验（同轮合并）

- **缩略图管线**：列表缩略图改为 canvas 缩小的独立小图（≤192px，内存 LRU 缓存 300 条，生成限并发 2）；生成中渲染等比占位块（呼吸动画），附件缺失渲染「图片已丢失」占位；全尺寸展示路径（展开区/预览面板/全屏）改走 Blob URL 缓存（淘汰即 revoke，内存约省一半），dataURL 仅保留给粘贴/复制/OCR 等宿主 API 路径
- **图片尺寸/体积徽标**：保存时解析图片头（PNG/GIF/WEBP/JPEG，不解码像素）写入 memo 元数据；旧数据与导入数据自动回填；列表元信息行与预览面板展示 `800×600 · 3.2 KB`
- **悬浮快览**：悬停缩略图约 0.3s 在光标旁弹出快览浮层（≤480px 大图按需生成），带复制图片/全屏/系统打开快捷操作，点击快览图展开条目；列表滚动自动关闭
- **「图片」筛选 chip**：按类型过滤含图备忘（Tab 循环切换已包含）
- **网格墙视图**：「图片」筛选下可切换等尺寸缩略图网格（持久化设置；列数随宽度自适应，固定格宽做算术窗口化支持大数据量），点击格子直进全屏，右键菜单与列表一致；多选模式自动回落列表行
- **全屏查看增强**：`←/→` 或左右按钮翻页（含 `n / n` 计数）；滚轮以光标为锚点缩放（光标下内容不漂移）；右下角缩放百分比徽标（点击复位）
- 图片条目折叠态：缩略图按**顶部裁切**；无备注无 OCR 的纯图条目用更大缩略图（64px）；缩略图/网格图解码完成后 150ms 淡入
- 敏感图片条目从「隐藏缩略图」改为**模糊显示**（blur 9~12px），保留"这条有图"的感知；快览与全屏仍被遮罩拦截
- 修复图片条目附件丢失时列表无声消失的问题（现在有明确占位提示，与粘贴路径的 toast 一致）

## [0.4.0] - 2026-10-25

按「数据安全优先、键盘优先兑现、批量管理补齐」的一次全面修缮。**破坏性变更：回收站功能整体移除**——删除即物理删除（删除前自动快照 + 5 秒撤销 Toast + ⌘/Ctrl+Z），旧版回收站中的遗留条目在升级后首次启动时被物理清理。

### 移除

- **回收站**：删除不再进软删除，回收站视图、30 天保留、清空回收站一并移除（工具定位是"速贴"，删除撤销已足够安全）

### 新增

- **批量操作**：⌘/Ctrl+A 进入多选模式，条目复选框 / Shift+点击范围选择 / 全选；批量浮条支持移到分组、加标签、删除所选（应用内确认 + 撤销，图片随撤销还原）
- **图文混排备忘**：图片与文字可共存——文字作为备注参与搜索与展示，粘贴的仍是图片本体
- **占位符大幅增强**：偏移日期 `{date+1}` `{date-2w}` `{date+1m}` `{date+1y}`（可组合格式 `{date+1d:MM月DD日}`，weekday/time/datetime 同样支持）；`{random:1-100}` 区间整数与 `{random:6}` 数字串；`{choice:a|b|c}`；格式串方括号字面量 `[文字]`（ADD/HHmm 不再被误替换）
- **搜索语法**：排除词 `-词`、引号精确短语 `"词组"`；`@分组` 支持拼音；搜索结果尊重置顶
- **第三方导入**：Espanso（.yml，含块标量）、Alfred snippets、通用 snippets JSON（Raycast 等导出结构）；本应用导出的 CSV / Markdown 支持往返导入（分组/标签/触发词保留）
- **regex 入口**：主搜索栏输入 URL / 邮箱 / 手机号 / IPv4 时提示「存为备忘」
- **快捷键帮助面板**（? 键或分组栏按钮）：全部快捷键集中可查，Windows 键符正确显示 Ctrl
- **键盘补齐**：Home/End 跳首末条、PageUp/PageDown 翻页、⌘/Ctrl+Z 撤销上一步、Menu/⇧+F10 键盘唤起右键菜单（菜单内 ↑↓/回车可用）
- **编辑器**：「保存并新建」（⌘/Ctrl+⇧+Enter）批量录入；textarea 内 Tab 输入缩进；标签输入联想已有标签；触发词实时冲突提示；标题回车跳正文
- **云同步感知**：`onDbPull` 到达时刷新列表（编辑中不打断）；`onPluginDetach` 分离窗口时行内编辑与草稿兜底落库
- 粘贴恢复剪贴板：原剪贴板为**图片**时一并备份恢复（此前会被文本覆盖丢失）；导出默认落在系统下载目录

### 修复（数据安全）

- **恢复备份不再先物理清空**：改为整体写回（附件随文档存活，图片通常无损），快照后新建的条目保留；备份被截断（>500 条）时明确警示并需确认
- **「移除图片」删除重建失败时回写原文档**——此前重建失败会直接丢掉整条备忘
- **写路径普遍检查结果**（使用统计/置顶/移动分组/加标签/排序等失败现在会提示），db 写冲突自动用最新 `_rev` 重试一次
- **合并导入按修改时间保护本地**：本地较新的条目不再被导入的旧版静默覆盖；判重指纹计入标签/分组/触发词/置顶，不再静默跳过；悬空 groupId 自动归位未分组
- **内容上限统一为 UTF-8 字节口径**——9 万汉字（270KB 字节）不再绕过 256KB 限制入库；容错读取对超长 content/标题/关键词/OCR 文本截断保留
- 导出 Markdown 代码围栏按内容自适应加长（内容含 ``` 不再破坏结构）；CSV 列扩充（敏感/更新时间/触发词）且可往返
- 裸 base64 图片载荷需通过文件头魔数校验（长十六进制串不再被误判为图片建出坏条目）

### 修复（交互）

- **Tab 焦点陷阱**：焦点在按钮/输入框上时 Tab 恢复原生移动（撤销按钮键盘可达），仅在列表背景上切换分组
- **双击条目不再触发粘贴**（双击只选词，此前会把整条内容误粘贴到上一个应用）
- **组件级回车补齐 IME 防护**（填写框/编辑器新建分组/分组管理弹窗）——拼音选字回车不再误确认
- Alt+↑↓ 在非手动排序下提示而不是静默改写 order 数据
- 智能排序：新建未使用的条目不再沉底（按创建时间参与新近度衰减）
- 拖拽排序支持拖到视口边缘时自动滚动；预览面板切换条目时滚动复位；切换分组后列表回顶
- 撤销类 Toast 不再被后续 Toast 挤掉；图片 dataURL 缓存 LRU 淘汰（48 张上限，可回源）；分组栏溢出渐隐提示 + 垂直滚轮横向滚动
- 全屏看图支持滚轮缩放 / 拖拽平移 / 双击复位；触屏设备图片操作条常显
- 原生 `window.confirm` 全部替换为应用内确认对话框（宿主 WebView 可能禁用原生对话框）；行内编辑保存后可 ⌘/Ctrl+Z 撤销
- `watchDark` 增加宿主应用级主题轮询（跟随系统模式下宿主内切主题插件也能跟随）

### 变更

- 导出 JSON 携带设置（导入时套用，偏好随数据迁移）；同标签多次 `{input}` 的非空默认值补齐（不再静默丢弃）
- 搜索内容索引改为全文（字面匹配不再截断 2000 字符；拼音转换仍截断以保证性能）；检索条目按 updatedAt 缓存，千条数据连续输入不再逐键重建拼音索引
- Markdown/CSV 导出包含图片条目的备注文字
- preload 全面加固：绝对路径 + 隐藏目录拒绝、扩展名白名单、文本 16MB 上限、原子写（tmp+rename）、临时图片自动清理（≤60 个 / ≤24h），并纳入 ESLint 质量门
- 构建产物卫生：release 目录构建前清空（此前历史 hash 产物累积到 5MB 死文件）、发布 plugin.json 剥离 development 字段、校验 preload 存在与版本号一致性；dev server 改 strictPort（端口冲突直接报错而不是静默换端口导致宿主白屏）
- 全部用户可见文案（含分组管理、预览元信息等约 40 处硬编码）归位 i18n 字典
- 示例数据新增触发词与行内代码演示条目；双反引号内嵌单反引号按 Markdown 语义解析
