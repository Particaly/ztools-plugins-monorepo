# 手动测试清单（发布前逐项验证）

> 环境：ZTools + 本插件（开发载入 `npm run dev` 或安装 `release/snap-memo`）。
> 打勾标准：每项在 **macOS 与 Windows** 各验证一次（Linux 尽力）。
> 已验证宿主版本：__________（填写 ZTools 版本号，OCR / 动态 Feature / onDbPull 等宿主能力的结论均锚定该版本）

## 1. 入口

- [ ] 主搜索栏输入「备忘 / 备忘录 / memo / 片段 / snippet / 速贴」→ 回车打开列表，子输入框立即可输入
- [ ] 任意应用选中文本 → 唤起 ZTools → 「存为备忘」→ 编辑器打开且内容已预填
- [ ] 主搜索栏「新建备忘 / 记一下」→ 编辑器打开且预填剪贴板文本（剪贴板有文本时）
- [ ] 主搜索栏输入 URL / 邮箱 / 手机号 / IPv4 → 出现「存为备忘」（regex 入口）→ 回车进入编辑器且内容预填
- [ ] regex 入口：普通词（如「备忘本」）不触发；超过 500 字符的长串不触发
- [ ] 复制一段已存在备忘的内容再走「存为备忘」→ 出现重复提示

## 1b. 图片备忘（图文混排）

### 1b-1. 混排编辑器

- [ ] 编辑器正文 Ctrl/⌘+V 粘贴截图 → 图片以**行内缩略图**嵌在正文光标处（不是独立预览区），可继续在图片前后输入文字
- [ ] 从桌面/文件夹**拖入图片文件**到正文 → 落点处插入行内图片；拖入非图片文件无反应
- [ ] 编辑器右上角图片按钮 → 选择 png/jpg 文件 → 插入光标处（编辑器未聚焦时追加到末尾）；选择 txt 被拒并有提示
- [ ] 行内图片退格一次整图删除；点击图片为整体选中（不再进入文字光标模型）
- [ ] 粘贴**富文本**（从浏览器复制带样式段落）→ 只落纯文本，无样式残留
- [ ] Enter 换行、Tab 两空格缩进与原 textarea 一致；中文 IME 组合输入正常（组合期间不上抛）
- [ ] 同一备忘粘贴多张图（含图片之间的文字）→ 保存后图文顺序与编辑时一致；单条最多 32 张，超限提示
- [ ] 大于 8MB 图片 → 插入被拒并有提示

### 1b-2. 展示与粘贴语义

- [ ] **纯图条目**（正文只有图片）→ Enter 仍粘贴**图片本体**；折叠行左侧大缩略图（同旧版）
- [ ] **混排条目**（文字 + 图片）→ Enter 粘贴**文字**（图片标记剥离，不残留 `{img:` 字样）；摘要中图片为小徽标，**点击徽标复制该图**
- [ ] 混排条目展开区/预览面板 → 行内图片为限高缩略图；**点击复制图片、双击进入全屏**
- [ ] 混排条目元信息行显示张数（如「3 张 · 800×600」）；文字部分与图片 OCR 文字均可被搜索命中
- [ ] 复制一张图片后「新建备忘 / 记一下」→ 图片直接排进正文
- [ ] 图片拖入 ZTools 主搜索栏 → 「存为图片备忘」→ 编辑器打开且图片已在正文；重复拖同一张图出现重复提示
- [ ] 拖一段**非图片长文本**（如长十六进制串）到搜索栏 → 不被误判为图片
- [ ] 纯图条目展开大图：点击图片本体切换宽度撑满；右下角「全屏查看」「用系统看图软件打开」（触屏常显）
- [ ] 「全屏查看」→ 滚轮缩放、拖拽平移、双击复位；`←/→` 在当前列表**全部图片**（跨条目、含混排行内图）间翻页；Esc 关闭
- [ ] 「用系统看图软件打开」→ 系统看图应用打开；**连续打开 5+ 次后检查临时目录 snap-memo 子目录自动清理**（保留 ≤60 个、≤24h）
- [ ] 混排条目编辑 → 改文字保存 → 图片仍在且位置不变；删除某张行内图片保存 → 仅该图消失
- [ ] 复制条目（创建副本）→ 副本图片独立可用；修改副本图片不影响原图
- [ ] 删除含图条目 → 5 秒内撤销 → **全部图片随条目完整恢复**
- [ ] 敏感含图条目 → 列表与预览都被遮罩，点眼睛临时显示
- [ ] 预览面板：含图条目点击正文**不进入行内编辑**（走「编辑」按钮进完整编辑器）

### 1b-3. 旧数据迁移（升级验证）

- [ ] 升级前已有的纯图备忘 → 正常显示为大图条目；Enter 仍粘贴图片本体
- [ ] 升级前「图片 + 备注」的条目 → 变为混排条目（图片在前、备注在后）；Enter 粘贴备注文字
- [ ] 升级后首次启动 → 旧附件搬迁到桩文档（`sm/att/`），编辑/换图/删除/粘贴全部正常；再次重启无重复迁移现象

### 1b-4. 导入导出

- [ ] 导出 JSON 的 images 按「槽 ID → 像素」携带；删除全部数据后重新导入 → 混排条目的图片完整还原且位置正确
- [ ] 导入**旧版本导出的 JSON**（images 按 memoId 键）→ 图片正常还原
- [ ] 同一份 JSON 导入两次（合并）→ 第二次全部跳过，无重复条目
- [ ] 导出 Markdown / CSV → 图片标记替换/剥离为 `[图片]` 或纯文字，无 `{img:` 残留；导出文件可再导入

## 1d. 图片 OCR

- [ ] 默认设置下保存图片备忘 → 不发起任何识别请求；预览面板显示「在设置中开启…」提示
- [ ] ZTools「设置 → 提供商」中启用一个 OCR 提供商（如微信 OCR）并设为默认 → 本插件设置页开关可开启
- [ ] 开关开启后保存含文字截图 → 自动识别；「保存并新建」路径同样触发
- [ ] 用识别出的文字（中文/英文）检索 → 图片条目命中并高亮；拼音首字母同样可命中
- [ ] OCR 提供商返回异常结构 / 超时 → Toast 识别失败，功能不崩
- [ ] 浏览器开发态 → 设置页显示「当前宿主不支持 OCR 提供商」，开关禁用

## 3. 粘贴（核心，前台应用逐一验证）

前台应用至少覆盖：记事本/文本编辑器、浏览器输入框（含多行）、IDE（VS Code / JetBrains）。

- [ ] Enter：内容粘贴到前台应用光标处，多行内容换行完整、无多余缩进
- [ ] Shift+Enter：仅复制，Toast 提示，不隐藏窗口
- [ ] Alt+1~9：先点击任一条目把焦点交给插件页，再按 Alt+数字，粘贴对应序号条目
- [ ] 设置改为「仅复制」后：Enter 复制、Shift+Enter 变为粘贴（互为反向）
- [ ] 开启「粘贴后恢复剪贴板」：先复制 A → 粘贴备忘 B → 约 0.5 秒后再 Ctrl/Cmd+V 粘出的是 A
- [ ] **原剪贴板是图片时开「恢复剪贴板」**：粘贴文本备忘后原图片可再粘贴回来（不再被覆盖丢失）
- [ ] 终端（可选）：部分终端拦截模拟粘贴，确认降级提示清晰

## 4. 占位符

- [ ] `{date}` `{time}` `{datetime}` `{weekday}` `{timestamp}` `{uuid}` 粘贴时正确解析
- [ ] `{date:YYYY年MM月DD日}`、**`{datetime:YYYY/MM/DD HH:mm}`（自定义格式生效）**正确
- [ ] **偏移日期**：`{date+1}`（明天）、`{date-1}`（昨天）、`{date+1w}`、`{date+1m}`、`{date+1y}`、`{weekday+1}`、`{date+1d:MM月DD日}`
- [ ] **`{random:1-100}`、`{random:6}`、`{choice:甲|乙|丙}`** 输出符合定义
- [ ] **格式串字面量**：`[ADD] YYYY-MM-DD` 输出 `ADD 2026-…`（方括号内容不参与替换）
- [ ] `{clipboard}` 注入粘贴时的剪贴板文本
- [ ] `{input:姓名=张三}`：Enter 后弹填写框，Tab 切换、Enter 确认（**拼音输入法选字回车不误确认**）、Esc 取消
- [ ] 同标签 `{input:名}` 与 `{input:名=张三}` 混用 → 填写框默认值取「张三」
- [ ] `\{date}` 输出字面量；`${x}`、`{foo}` 等未知占位符原样保留
- [ ] 编辑器内修改内容，右侧解析预览实时更新

## 5. 批量操作（多选）

- [ ] ⌘/Ctrl+A 或分组栏「多选」按钮 → 进入多选模式，条目左侧出现复选框、序号徽标隐藏
- [ ] 点击条目 / 空格 / Enter 切换选中；Shift+点击范围选择；「全选」按钮全选/清空
- [ ] 批量浮条：移到分组（分组即时创建于导入场景除外）；加标签（可连续加多个）；删除所选
- [ ] 批量删除 → 应用内确认对话框（Enter 确认 / Esc 取消）→ 删除后 Toast 带「撤销」；**撤销后全部条目（含图片）恢复**
- [ ] Esc 退出多选模式；再次进入时选中集合已清空

## 6. 错误与数据健壮性

- [ ] 删除条目 → Toast 带「撤销」，5 秒内点击恢复；**⌘/Ctrl+Z 也可触发撤销**
- [ ] 导出 JSON（含设置）→ 清空 → 导入（覆盖，需二次确认）→ 数据与设置一致
- [ ] 导入（合并）重复导入同一文件 → 全部跳过；**本地较新的修改不会被导入的旧版覆盖**
- [ ] 文本导入：本应用导出的 CSV / Markdown 往返还原（分组/标签/触发词保留）；Espanso `.yml` 导入 trigger/replace；Alfred `.alfredsnippets`（JSON 入口）导入
- [ ] 手工把某条 db 文档改坏（开发者工具）→ 列表仍可打开，坏条目被跳过并提示
- [ ] **旧版本回收站数据升级**：带 deletedAt 的旧文档在启动后被物理清除，不出现在列表
- [ ] **恢复备份不再先清空**：批量误删后恢复备份 → 条目与图片（未删文档的）完整回来；备份之后新建的条目保留
- [ ] 备份超过 500 条时：数据页显示「备份不完整」警示，恢复前弹确认
