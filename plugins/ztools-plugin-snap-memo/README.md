# 速贴备忘（snap-memo）

> ZTools 插件：在主搜索栏唤起，毫秒级检索保存的备忘与常用片段，**回车直接粘贴到当前正在使用的应用**。

## 功能一览

- **极速检索**：同时匹配标题、内容、标签、分组名、触发词与**图片 OCR/文字内容**；支持**中文全拼与拼音首字母**（`huiyi` / `hyyq` 都能命中「会议」，`@gongzuo` 能命中「工作」分组）、大小写不敏感、全角归一；**排除词**（`会议 -延期`）与**引号精确短语**（`"west lake"`）；命中片段高亮（全角查询命中半角原文时位置同样正确）；搜索结果尊重置顶
- **回车即贴**：Enter 粘贴到前台应用（三级降级链，见下）；Shift+Enter 仅复制；`Alt+1~9` 快速粘贴可见列表前 9 条；**纯图条目粘贴图片本体**
- **快捷复制**：`` `代码` `` 片段渲染为代码 chip，**鼠标点一下或键盘聚焦回车即复制**（双反引号内嵌单反引号按 Markdown 语义）
- **图文混排**：图片直接嵌在正文里与文字原地排版（一条备忘可含多张图，单图 ≤8MB、至多 32 张）——编辑器 `Ctrl/⌘+V` 粘贴图片、拖入图片文件即在光标处插入行内图片（退格整图删除）；工具栏插入图片文件、复制图片后「新建备忘」自动带入、把图片拖入搜索栏「存为图片备忘」。**粘贴语义**：纯图条目（正文只有图片）回车贴**图片本体**；混排条目回车贴**文字**（图片标记剥离），列表摘要里的图片徽标与展开区的行内图**点击即复制该图**、双击全屏。文字与图片 OCR 均参与搜索；点击切换大图，悬浮右下角可**全屏查看**（滚轮以光标为锚点缩放/拖拽平移、`←/→` 在当前列表全部图片间翻页）或**用系统看图软件打开**
- **图片体验管线**：列表缩略图走**缩略图管线**（canvas 缩小的独立小图 + 内存 LRU，滚动不再解码原图；全尺寸展示走 Blob URL 省一半内存）；生成中显示等比占位块、附件缺失显示「图片已丢失」；纯图条目折叠态用更大缩略图，截图按**顶部裁切**；混排条目摘要用图片徽标、展开区用限高行内图；元信息行显示**张数/尺寸/体积徽标**（保存时解析图片头，旧数据自动回填）；**悬浮缩略图约 0.3s 弹出快览浮层**（复制图片/全屏/系统打开，不用展开条目）；敏感图片条目**模糊显示**而非隐藏；「图片」筛选 chip（含全部带图条目）可切换**网格墙视图**（等尺寸缩略图格，点击直进全屏）
- **图片文字识别（OCR）**：设置内开关（默认关）。开启后保存含图条目时自动调用 **ZTools OCR 提供商**（`ztools.ocr`，走你在「设置 → 提供商」中设为默认的提供商，如微信 OCR / AI 识图）**逐张**识别图中文字（已识别过的图不重复计费），识别结果参与检索——识别过的截图用文字就能搜到
- **智能排序**：置顶 > 匹配得分 > 使用频率×最近活跃（frecency，**新建未用的条目不沉底**）；无搜索词时按设置排序
- **占位符**：`{date}` `{time}` `{datetime}` `{weekday}` `{timestamp}` `{clipboard}` `{uuid}` `{random:1-100}` `{choice:a|b|c}`、自定义格式 `{date:YYYY-MM-DD}`、**偏移日期** `{date+1}` `{date-2w}` `{date+1m}` `{date+1y}`（`weekday`/`datetime` 同样支持，可组合格式）、格式串字面量 `[ADD]`、粘贴前填空 `{input:姓名=张三}`；`\{xxx}` 保留字面量；编辑时实时预览
- **分组 / 标签 / 置顶 / 敏感遮罩**：分组管理（颜色、排序、删除时选择条目去向）；标签输入带联想；敏感条目列表与预览默认遮罩，点眼睛临时显示
- **批量管理**：`Mod+A` 进入多选，复选框 / Shift+点击范围选择 / 全选；一键**移到分组 / 加标签 / 批量删除**（确认 + 撤销，图片随撤销还原）
- **删除即删除（无回收站）**：删除前自动快照，5 秒撤销 Toast + `Mod+Z` 兜底，保持工具轻快
- **导入导出**：JSON（合并/覆盖、数量预览、按 ID 与内容双重去重、**本地较新时保留本地**、图片按「槽 ID → 像素」随 JSON 携带、重分配 ID 时正文图片标记同步改写，旧版导出天然兼容）、Markdown、CSV（**均支持往返导入**）；**第三方迁移**：Espanso（.yml）、Alfred snippets、通用 snippets JSON（Raycast 等导出结构）；纯文本导入；批量操作前自动本地快照，可一键恢复（恢复不再先清空数据）
- **动态触发词**：给任意备忘设置触发词（如 `addr`），在 ZTools 主搜索栏输入后回车**免开界面直接粘贴**（依赖宿主动态 Feature，能力缺失时自动隐藏）
- **regex 快存入口**：在主搜索栏输入 URL / 邮箱 / 手机号 / IP 时提示「存为备忘」
- **云同步友好**：宿主数据同步开启时，云端数据到达自动刷新列表（编辑中不打断）；写冲突自动重试
- **明暗主题**：跟随宿主（含 `--plugin-primary-color` 主题色注入），浏览器开发态回退 `prefers-color-scheme`
- **虚拟滚动**：条目 > 300 时窗口化渲染（行高按内容实测，支持完整模式与条目展开），1000 条数据下输入检索无卡顿；检索条目按编辑状态缓存，连续输入不重复建拼音索引

不做的：云端账号与自建同步、插件自身发起的网络请求与埋点、回收站（删除有快照 + 撤销兜底）。数据全部存放在 ZTools 本地数据库；唯一的外部调用是图片 OCR——经宿主 `ztools.ocr` 走**你配置的 OCR 提供商**（如微信 OCR 离线识别，或 AI 识图按所选模型计费），关闭开关即完全不发生。

## 安装与开发

要求 Node.js ≥ 18。

```bash
npm install
npm run dev        # 浏览器 mock 开发（http://localhost:5183，localStorage 充当存储；端口被占直接报错）
npm run test       # Vitest 单元测试（纯函数内核 + 存储仓库）
npm run typecheck  # vue-tsc 类型检查
npm run lint       # ESLint（含 preload）
npm run build      # 类型检查 + 构建 + 生成 release/snap-memo（可直接提交插件仓库）
```

在 ZTools 中调试：`public/plugin.json` 已配置 `development.main` 指向 `http://localhost:5183`，用「插件开发」载入本目录即可热更新调试。

发布：`npm run build` 后 `release/snap-memo/` 即完整插件目录（构建前自动清空、剥离 development 配置并校验版本一致性）；向官方仓库提 PR 时把该目录内容放到 `plugins/snap-memo/`。

## 快捷键

`Mod` 在 macOS 为 `⌘`，其余平台为 `Ctrl`。宿主保留 `⌘/Ctrl+D`（分离窗口）与 `⌘/Ctrl+Q`（终止插件），因此复制条目使用 `Mod+Shift+D`（`Mod+D` 在浏览器开发态可用作别名）。**面板内按 `?` 可随时查看完整快捷键帮助。**

| 操作 | 快捷键 |
|---|---|
| 上/下移动选中（边界循环） | ↑ / ↓ |
| 跳到首条 / 末条 / 翻页 | Home / End / PageUp / PageDown |
| 全屏图片内翻页（循环） | ← / → |
| 粘贴 / 仅复制 | Enter / Shift+Enter |
| 快速粘贴第 N 条（N=1~9） | Alt+1 ~ Alt+9 |
| 切换分组 | Tab / Shift+Tab（焦点在输入框或按钮上时 Tab 恢复原生移动） |
| 预览面板开关 | Space（搜索框为空且页面聚焦时）/ Mod+P |
| 新建 / 编辑 / 创建副本 | Mod+N / Mod+E / Mod+Shift+D |
| 保存 / 保存并新建（编辑器内） | Mod+Enter / Mod+Shift+Enter |
| 撤销上一步（删除等） | Mod+Z |
| 进入/退出多选 | Mod+A |
| 打开选中条目右键菜单（菜单内 ↑↓/回车可用） | Menu / Shift+F10 |
| 置顶切换 | Mod+Shift+P |
| 删除（撤销 Toast 5 秒 + Mod+Z） | Delete / Backspace |
| 手动排序微调（仅"手动"排序下生效） | Alt+↑ / Alt+↓ |
| 快捷键帮助 | ? |
| 聚焦搜索 | / 或 Mod+F |
| 逐层返回 / 退出 | Esc（弹窗 → 多选 → 清搜索 → 退出插件） |

说明：ZTools 子输入框聚焦时，宿主只向插件转发 ↑/↓/Tab/Enter（含修饰键）；`Alt+数字`、`Space` 等在点击列表把焦点交给页面后生效。

## 占位符语法

| 占位符 | 结果示例 |
|---|---|
| `{date}` `{time}` `{datetime}` `{weekday}` | 2026-10-25 / 14:30:08 / 2026-10-25 14:30:08 / 星期日 |
| `{date:YYYY/MM/DD}` `{time:HH点mm分}` `{datetime:YYYY/MM/DD HH:mm}` | 2026/10/25 / 14点30分 / 2026/10/25 14:30 |
| `{date+1}` `{date-1}` `{date+1w}` `{date+1m}` `{date+1y}` | 明天 / 昨天 / +7天 / 下个月 / 明年（`{weekday+1}`、`{date+1d:MM月DD日}` 可组合） |
| `{timestamp}` | 1792353008123（毫秒） |
| `{random:1-100}` `{random:6}` | 闭区间随机整数 / n 位随机数字串 |
| `{choice:甲\|乙\|丙}` | 随机取一项 |
| `{clipboard}` | 粘贴时的剪贴板文本（宿主 preload 读取，不可用则置空） |
| `{uuid}` | 随机 UUID v4 |
| `{input:姓名}` `{input:工号=0001}` | 粘贴前弹填写框；支持默认值（同标签多次出现时补齐非空默认值） |
| `[ADD] YYYY-MM-DD` | 格式串内方括号包裹字面量，`ADD`/`HHmm` 等不再被误替换 |
| `\{date}` | 字面量 `{date}`（反斜杠转义） |

未知花括号（如代码里的 `${x}`、`{foo}`）原样保留，不会破坏代码片段。格式串支持 `YYYY YY MM DD HH mm ss SSS`，其余字符原样输出。

## 数据与隐私

- 全部数据仅存于 ZTools 本地数据库（`db` / `dbStorage`），每条备忘一个文档（`sm/memo/<id>`），分组、设置、快照各自独立文档；图片像素按「每图一槽」存为独立桩文档（`sm/att/<槽ID>`）的**附件**（`db.postAttachment`），不进入同步正文；旧版挂在 memo 文档上的附件启动时自动搬迁
- 插件自身**不发起任何网络请求**，不含遥测/统计；图片 OCR 是唯一的外部调用，经宿主 `ztools.ocr` 转发到你在「ZTools 设置 → 提供商」中启用的 OCR 提供商（微信 OCR 为离线识别），且仅在开关开启并保存/手动识别图片时发生
- 敏感遮罩只是显示层遮罩，**不是加密**；如需加密请配合宿主或系统级方案
- 导入导出经 preload 受控文件接口：仅允许绝对路径、非隐藏目录、白名单扩展名（json/txt/md/csv/yml/yaml）与 16MB 上限，写入为原子替换；图片读取走扩展名白名单 + 8MB 上限
- 删除为物理删除，但每次批量操作前自动快照（最近一份，上限 500 条、不含图片像素）；恢复备份**不会先清空现有数据**，快照之后新建的条目不受影响

## 架构速览

```
src/
├─ core/        纯函数内核（占位符/检索/拼音/frecency/迁移/容错/导入导出/图片 dataURL/行内图片标记/行内代码/OCR 契约提取）—— Vitest 全覆盖
├─ platform/    平台适配层（ZTools 宿主封装 + 浏览器 mock 双实现，全部特性检测+降级；
│               图片复制/粘贴/附件、OCR 提供商调用、分离窗口/云同步事件均在边界处特性检测）
├─ store/       repository（文档与槽附件存储映射，Vitest 覆盖）+ appStore（reactive 状态与动作）
├─ components/  自研组件（无 UI 库，内联 SVG 图标；MixedEditor 图文混排编辑器（contenteditable）；
│               RichText 负责行内代码 chip、行内图片与高亮）
├─ i18n/        简体中文文案（集中管理，预留多语言结构）
└─ styles/      CSS 变量主题（明/暗、密度、宿主主题色）
public/preload/services.cjs   受控 preload：文件读写（白名单+原子写）+ 剪贴板文本/图片读取 + 临时图片管理
```

粘贴降级链：`hideMainWindowPasteText` → `copyText + hideMainWindow + simulateKeyboardTap(Cmd/Ctrl+V)` → 仅复制并提示。所有 ZTools API 均在运行时做能力检测，缺失时按 [docs/PLAN.md](docs/PLAN.md) 的核实表降级。
